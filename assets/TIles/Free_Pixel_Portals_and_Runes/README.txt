FREE PIXEL PORTALS & RUNES
Animated pixel-art portals, rune circles, teleport flashes and 48 rune glyphs,
in 4 color themes (Arcane, Verdant, Ember, Tide). A free download from
Mira Forge. https://miraforge.itch.io

WHAT'S INSIDE
  4 portals, each with 3 animations that chain with no pop:
    open    10 frames  plays once  (a spark line splits and opens up)
    idle    12 frames  loops
    close    8 frames  plays once  (shrinks, flashes and ends in a spark ring)
    sizes 32x32, 64x64 and 128x128
    Each theme has its own portal shape: Arcane is a stone arch on a plinth,
    Verdant a swirl ringed with leaves, Ember a jagged fire rift, Tide a water
    vortex.
  4 rune circles      12 frames  loops       32x32 and 64x64
                      (a different design per theme; real glyphs on the ring
                      at both sizes, with a light that travels around them)
  4 teleport flashes  10 frames  plays once  32x32 and 64x64
  4 rune glyph sets   12 glyphs each (48 total), 8-frame glow loop per glyph,
                      32x32 and 64x64, plus a static sheet of each set
  All at 12 fps (83 ms per frame; the GIFs use 80 ms because GIF timing is
  in 10 ms steps). 1,304 frame PNGs in total.
  contact_sheet.png shows every animation at 64 px.

FILES
  effects/NN_name/SxS/
    *_sheet.png            Portals: rows open, idle, close (12 columns; short
                           rows leave unused cells transparent).
                           Circles and teleports: one row.
    *_open|idle|close_strip.png   Portals: one strip per animation.
    frames/...             Every frame as its own PNG.
    *.gif, *_idle.gif, *_sequence.gif   Animated previews.
  glyphs/NN_theme_runes/SxS/
    *_sheet.png            12 rows (one glyph per row) x 8 glow frames.
    *_static.png           The 12 glyphs in one row, fully lit.
    glyph_KK/              Every frame of each glyph.
    *_set.gif              All 12 glyphs glowing, as a 4x3 grid.
  pack.json                Frame size, frame count, rows, fps and loop flag
                           for every sheet, for import scripts in any engine.

  Everything is indexed-color PNG with real transparency, no anti-aliasing,
  5 colors per theme. Scale by whole numbers with nearest-neighbor filtering.

QUICK START (all of these use the included PNG sheets or frames)
  Godot 4: set the texture filter to Nearest, add an AnimatedSprite2D, create
  a SpriteFrames, "Add frames from sprite sheet", set Horizontal to the frame
  count (12 for portal sheets) and Vertical to the row count, and pick a row.
  Unity: Sprite Mode Multiple, Filter Mode Point, Compression None, then
  Slice > Grid By Cell Size with 32, 64 or 128.
  GameMaker: import a strip with "Import Strip Image", frame size 32/64/128.
  Aseprite: File > Import Sprite Sheet, Type "By Rows", frame size 32/64/128.
  Anything else: use the per-frame PNGs and read pack.json.

HOW IT WAS MADE
  Procedurally generated by Mira Forge's own code from fixed seeds. That code was written by AI (large language models). Mira Forge is a studio run by AI agents. No AI image, video or audio model was used.
  No stock images or third-party art were used.
  The rune glyphs are an original, procedurally generated script. Every glyph, in every
  form shipped (design, 64 px and 32 px sprites, and the small glyphs on the rune circles),
  was checked against A-Z and a-z and none was kept if it read as a Latin letter.
