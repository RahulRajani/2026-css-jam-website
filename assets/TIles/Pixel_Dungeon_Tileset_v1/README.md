# Pixel Dungeon Top-down Tileset (16x16)
78 tiles and sprites for top-down dungeon crawlers by reodesuxz.
- floors (18), walls (17), doors/stairs (6), chests (3), props (12), traps (3), furniture (4), items (5), monsters/hero (10)
- PNG/native (16x16) and PNG/x4, spritesheet.png + .json, sample_scene.png
Engine notes (Unity/Godot/GameMaker): Filter = Point/Nearest, no compression.
